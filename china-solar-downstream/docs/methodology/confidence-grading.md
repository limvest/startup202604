# 출처 신뢰도 등급 (Confidence grading)

**2026년 11월 개정판**

이 데이터셋의 수치에는 출처 등급(★1~★5)을 붙인다. 2026년 11월 점검에서 '★5인데 틀린 수치'가 여러 개 나와(예: 창웨이광푸 2024년 매출, 시그에너지 2024년 매출) 등급 기준을 더 엄격하게 고쳤다.

| 등급 | 기준 | 예 |
| --- | --- | --- |
| ★5 | 공시 원문(연차·반기보고서, 투자설명서, 상장 신청서), 정부·규제기관 기록을 **직접 확인** | 궈넝르신 2025년 연차, 시그에너지 홍콩 투자설명서, 한국 정책브리핑 |
| ★4 | 공시를 인용한 신뢰할 만한 업계 매체·증권사 보고서, 또는 독립 출처 2개 이상 | 정태안능 상장 신청서를 인용한 제일재경 보도 |
| ★3 | 매체 1곳 또는 회사 보도자료 1건 | 회사가 발표한 누적 계약 용량 |
| ★2 | 자체 마케팅 문구, 데이터베이스(Crunchbase 등) 단일 기록 | 기업 고객 수 자체 발표 |
| ★1 | 근거 없는 추론 | 회사 실체 미확인 |

## 2026년 11월 규칙 변경

1. **★5는 원문을 직접 확인한 경우에만 준다.** 매체가 '공시에 따르면'이라고 쓴 것은 ★4다.
2. **단위 확인:** 중국 수치의 '亿(억)'을 billion으로 옮기며 10배 틀린 사례가 있었다. 모든 위안화 수치는 '억 위안' 또는 'CNY bn'으로 단위를 명시한다.
3. **'없다'는 주장도 출처가 필요하다.** 특히 한국 쪽 '이런 사업·제도는 없다'는 주장은 정부·공공기관 자료로 확인한 뒤에만 쓴다. 5월판의 가장 큰 오류(대여사업, 소규모 전력중개 누락)가 여기서 나왔다.
4. **날짜를 붙인다.** 모든 수치에 기준 시점을 적는다.

## English

Grades ★5-★1 as above. Since November 2026: ★5 requires direct reading of the primary filing; media citing a filing is ★4. All CNY figures state units explicitly (亿 = 100 million). Claims that something does not exist (especially Korean programmes) need an official source. Every figure carries a date.
