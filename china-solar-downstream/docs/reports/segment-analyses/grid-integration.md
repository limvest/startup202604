# 분야 분석: 계통 통합 (VPP·저장·예측·거래) — 2026년 11월 신설

**2026년 11월 신설** · [English version](../en/segment-analyses/grid-integration.md)

2026년 5월판의 네 분야에는 '흩어진 자원을 계통에 맞춰 움직이는 층'이 없었다. 중국 136호 이후, 그리고 한국 출력제어 급증 이후 가장 확실하게 돈이 흘러가는 곳이 이 층이어서 다섯 번째 분야로 추가했다.

## 무엇을 하는 층인가

1. **예측:** 발전량·가격을 예측해 시장에 제출한다.
2. **제어:** 계통 운영자의 지시에 맞춰 출력을 줄이거나 저장으로 옮긴다.
3. **저장:** 남는 전기를 저장해 비쌀 때 판다. 용량 보상을 받는다.
4. **거래:** 소규모 자원을 묶어 도매시장·PPA·입찰에 참여시킨다.

## 중국

| 제도·지표 | 내용 |
| --- | --- |

| 136호(2025-02) | 재생에너지 시장가격 노출, ESS 병설 의무 폐지 |
| 114호(2026-01) | 독립형 ESS 등에 용량 보상 |
| 분산형 관측·제어(四可) 요구 | 궈넝르신 예측 장비 매출 +104.6%(2025) |
| 기업 | 궈넝르신(예측·거래, 19개 성), 썬그로우 iSolarCloud(유럽 VPP), 궈샤커지(ESS) |

## 판단

- 두 나라 모두 '물량(출력제어) 위험을 관리하는 사업자'의 몫이 커진다.
- 경쟁력은 예측 정확도, 제어 이행률, 시장 참여 자격, 저장 자산 확보다. 해줌은 준중앙급전 봄철 평균 이행률 96.19%를 공개했다.
- 한국에서 이 층은 대기업(LG에너지솔루션, HD현대일렉트릭), 발전 공기업, 전문 VPP(해줌, 그리드위즈, VPP랩)가 함께 경쟁하는 구도다.
