# 정책 연표: 중국·한국 태양광 다운스트림 (2013~2026)

**2026년 11월 개정판** · 기준일 2026-11-27 · [English version](en/policy-timeline.md)

중국 다운스트림의 사업모델은 거의 모두 정책 하나하나에 맞춰 생기고 사라졌다. 2025년 136호 문건이 가장 큰 단절이다. 한국은 2026~2027년에 비슷한 크기의 제도 전환을 맞는다. 구조화된 원자료는 `data/raw/policy-events.yaml`.

## 중국

| 시기 | 정책 | 다운스트림에 미친 영향 |
| --- | --- | --- |
| 2013-08 | 분산형 0.42위안/kWh 20년 고정 매입 | 주택용 설치사·리스사 진입의 출발점 |
| 2014-10 | 빈곤퇴치 태양광(光伏扶贫) | 정부 사업이 농가에 태양광을 '가져다주는' 유통 구조 형성 |
| 2018-05-31 | 531 신정책: 보조금 삭감, 분산형 보조 한도 | 자본 약한 설치사·P2P 금융 대거 퇴출 |
| 2020-09 | 2060 탄소중립 선언 | 분산형 재가속 |
| 2021-06 | 현 단위 지붕 태양광 시범(整县推进) | 국유·대형 민간 개발사 중심 재편, 지붕임대 모델 확산 |
| 2021 말 | 주택용 국가 보조금 종료(평가 연계) | 자가소비·임대 모델로 전환 |
| 2023~2024 | 다수 성에서 계통 연계 제한 | 주택용 2024년 약 1/3 감소 |
| 2025-01 | 분산형 태양광 개발건설 관리 규정 | '비자연인 주택용' 첫 정의, 큰 분산형의 전량 매입 폐지, 자가소비 요구 |
| 2025-02 | 136호 문건(新能源上网电价市场化改革) | 6월 1일 이후 신규는 시장가격 + 일부 차액정산. 재생에너지 ESS 병설 의무 폐지 |
| 2025-02 | 국가전력망 '光e宝' 해지 통보 | 주택용 리스의 전기요금 귀속 구조 흔들림 |
| 2025-04 | VPP 지침(357호) | VPP 독립 시장 주체, 2027년 20GW·2030년 50GW |
| 2025-05 | 보장 종료 전 서두른 설치 | 한 달 92.92GW, 2025년 연간 315GW |
| 2025 하반기 | 반내권(反内卷) 정책 | 저가 경쟁 규제, 가격 하한 압력 |
| 2025-12 | 첫 분산형 태양광 기관 간 REIT | 운영 자산의 자본 회수 경로 |
| 2026-01 | 114호 문건 | 독립형 ESS 등에 용량 보상 |
| 2026 | 5개 성, 신규 상공업용 분산형 보호가격 제외. 산둥은 비자연인 주택용도 제외 예정(시점은 보도마다 2026-06 또는 2027) | 2026년 상반기 분산형 -62.6% |

## 한국

| 시기 | 정책 | 영향 |
| --- | --- | --- |
| 2012 | RPS(공급의무화) 시행 | REC 시장 형성 |
| 2013~2021 | 태양광 대여사업 | 초기 투자 없이 대여료로 설치. 2021년 종료 |
| 2018-12 | 소규모 전력중개사업 시행 | 1MW 이하 재생에너지·ESS를 묶어 시장 거래. 초기 참여 저조 |
| 2024-06 | 제주 실시간시장·예비력시장·재생에너지 입찰제도 정식 시행 | VPP의 시장 참여 시범 |
| 2025-10-01 | 기후에너지환경부 출범 | 2030년 재생에너지 100GW 목표 |
| 2025 | 공공주차장 신재생 설치 의무화(시행령 개정) | 생활 공간 태양광 확대 |
| 2026-02 | 차세대 분산형 전력망 추진계획 | 유연접속, 배전망 ESS |
| 2026-03 | 재생에너지 준중앙급전 본격 시행 | 소규모는 VPP를 통해 출력제어에 참여하고 대가 수령 |
| 2026 | 햇빛소득마을 전국 확산(2030년 2,500곳 이상) | 마을 단위 묶음 보급, ESS는 민간 VPP 부담 |
| 2026-07 | 배전망 ESS VPP 9곳 선정 | ESS 128MW로 접속 대기 182.4MW 해소 |
| 2026-08 | 재생에너지 이격거리 상한 확정(도로 0m, 주거지 200m) | 입지 규제 완화 |
| 2026 말 | 신규 REC 발급 종료 | - |
| 2027-01-01 | RPS 개편 재생에너지법 시행(계약시장) | 한전 20년 장기계약, 가중치→우대가격, 현물시장은 2029년까지 |
